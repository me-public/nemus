# List Suites

List all saved suites (reusable collections of repos).

## Running

```bash
grove suite list
```

## Presenting Results

Show each suite's name and the repos it contains.

## Related

- `grove suite create` to create a new suite
- `grove suite use` to create a workspace from a suite
- `grove suite delete` to remove a suite
